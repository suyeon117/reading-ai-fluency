# 읽기쑥쑥 AI — 초등 읽기 유창성 웹앱

## 바로 실행하기 (코딩을 몰라도 가능)
1. ZIP 파일을 압축 해제합니다.
2. **Node.js 18 이상**을 설치합니다: https://nodejs.org/
3. 압축을 푼 폴더에서 터미널(Windows: PowerShell, Mac: 터미널)을 엽니다.
4. `npm start`를 입력합니다.
5. Chrome 또는 Edge에서 **http://localhost:3000** 을 엽니다.
6. 학년·주제·읽기 수준을 선택한 뒤 `내 이야기 만들기`를 누릅니다.
7. `읽기 시작`을 눌러 마이크 권한을 허용하고 읽은 후 `읽기 끝내기`를 누릅니다.

추가 패키지 설치(`npm install`)가 필요하지 않습니다.

## 기능
- 학년·주제·수준에 따른 오프라인 맞춤형 읽기 자료 구성
- 한국어 브라우저 음성 인식(Web Speech API)
- 원문과 인식된 음성의 어절 단위 편집 거리 정렬
- 일치·불일치 어절 강조 및 재읽기 안내
- 정확도와 분당 정확 어절 수 추정
- 브라우저 음성 합성(TTS)으로 모범 읽기 제공

## 기술 및 AI 요소에 관한 정확한 설명
- **AI 음성 인식**: 브라우저의 SpeechRecognition(Web Speech API)을 사용합니다. 지원 여부와 인식 품질은 브라우저 및 연결 상태에 따라 다릅니다. 일부 브라우저에서는 음성 인식을 위해 외부 서비스로 오디오가 전송될 수 있습니다.
- **맞춤형 글**: 현재 버전은 생성형 AI API를 사용하지 않습니다. 미리 작성한 주제별 문장을 학생 설정에 따라 조합하는 규칙 기반 기능입니다. 따라서 '생성형 AI가 글을 창작한다'고 소개하면 안 됩니다.
- **오류 분석**: 원문과 음성 인식 결과를 어절 단위로 비교하는 동적 계획법 기반 편집 거리 알고리즘입니다. 실제 발음 정확도를 직접 측정하지 않습니다.
- **속도**: 인식된 정확 어절 수를 소요 시간으로 나눈 추정값입니다. 정식 표준화 검사가 아닙니다.
- **녹음**: 이 버전은 마이크 입력을 음성 인식에 사용하며 **녹음 오디오 파일을 저장하지 않습니다**. 녹음 파일 저장이 필수라면 MediaRecorder 기능을 추가해야 합니다.
- **개인정보**: 앱 서버는 학생 이름이나 음성 파일을 저장하지 않지만, 브라우저의 음성 인식 서비스 정책은 별도로 확인해야 합니다. 아동 대상 사용 전 보호자 동의와 개인정보 검토가 필요합니다.

## 배포
이 프로젝트는 Node.js 서버가 포함된 웹앱입니다. Node.js 실행을 지원하는 호스팅(Render, Railway 등)에 GitHub 저장소를 연결하고 시작 명령을 `npm start`로 지정해 배포할 수 있습니다. 호스팅 플랫폼에서 제공하는 `PORT` 환경변수를 자동 사용합니다. 실제 공개 URL과 GitHub 주소는 소유자 계정에서 배포·업로드한 뒤 생성됩니다.

## 파일 안내
- `server.js`: 정적 웹 서버
- `public/index.html`: 화면
- `public/style.css`: 디자인
- `public/app.js`: 맞춤형 글·음성 인식·오류 분석
- `package.json`: Node.js 실행 설정
